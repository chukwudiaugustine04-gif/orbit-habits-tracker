# Orbit Habits Tracker 🪐

A responsive web application for setting daily habits, tracking completion streaks, and monitoring progress over time. Built with React, TypeScript, Supabase, and Tailwind CSS.

Live Demo: [orbit-habits-tracker.vercel.app](https://orbit-habits-tracker.vercel.app/)

---

## Features

- Habit Management: Create, edit, and organize daily habits with custom schedules.
- Streak & Analytics: Tracks consecutive completion streaks and visualizes historical progress.
- Data Persistence: Uses Supabase for data storage and user preference syncing across sessions.
- Progressive Web App (PWA): Configured with Vite PWA for installability and offline support.
- Responsive Design: Optimized layout for mobile, tablet, and desktop viewports.

---

## Tech Stack

- Framework: React 18, Vite
- Language: TypeScript
- Styling: Tailwind CSS
- Backend / Database: Supabase
- Deployment: Vercel
